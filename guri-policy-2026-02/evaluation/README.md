# 구리시 정책제안 공모전 아이디어 평가 기준

`guri-policy-2026-02/`에 올라오는 아이디어를 3시간마다 검토해 점수를 매긴다. 이 폴더의 파일 구성은 다음과 같다.

| 파일 | 내용 |
|---|---|
| `README.md` | 평가 기준(이 문서). 모든 회차에 같은 기준을 적용한다 |
| `YYYY-MM-DD-HHMM-review.md` | 검토 시각별로 새로 평가한 아이디어의 항목별 점수와 판단 근거 |
| `scoreboard.md` | 지금까지 평가한 전체 아이디어의 누적 순위, 등급별 목록, 검토를 마친 원본 파일 목록 |

## 채점표 (100점)

공모전 공고의 세부 심사기준표를 확보하지 못해, 지자체 정책제안 공모전에서 흔히 쓰는 창의성·실현가능성·효과성·구체성에 공모전 경쟁력과 근거 신뢰도를 더해 구성했다.

| 항목 | 배점 | 높은 점수 | 낮은 점수 |
|---|---|---|---|
| ① 문제 실재성·지역 근거 | 20 | 최근(2025~2026) 구리시 공식 답변·자료에서 장소와 불편이 특정되고 시가 제약을 인정함 | 오래된 민원(2023년 이전), 후기·비공개 제목 한 건, 근거 없는 가설, 비공식 출처 |
| ② 시민 체감 효과·파급력 | 25 | 안전·건강·교통약자·아동·육아처럼 중요도가 높고, 수혜자가 많거나 시 전역으로 확대할 수 있음 | 소수 이용자의 편의, 몇 분의 시간 절약, 단일 시설 운영 미세조정 |
| ③ 실현가능성·비용 | 20 | 기존 예산·인력·시설 안에서 시가 단독 시행할 수 있음 | 경찰·민간업체·사유지 협조나 신규 예산이 필요하고 법·책임 문제가 남음 |
| ④ 창의성·차별성 | 15 | 시가 '안 된다'고 답한 제약을 우회하는 해법, 기존 사업과 명확히 다른 접근 | 이미 일반적인 행정 관행이거나 안내문 수정 수준 |
| ⑤ 구체성·검증 설계 | 10 | 측정지표, 비교 방법, 보류 조건이 명확함 | 지표나 실행 주체가 모호함 |
| ⑥ 공모전 경쟁력 | 10 | 제목만 봐도 문제와 해법이 보이고, 심사위원이 바로 체감하며, 시정 방향과 맞음 | 행정 내부 절차 개선이라 시민 눈에 잘 보이지 않음 |

## 등급

| 등급 | 점수 | 의미 |
|---|---|---|
| S | 80 이상 | 바로 제안서로 발전시킬 1순위 |
| A | 75~79 | 본선 경쟁력 있음. 보완 후 제출 |
| B | 68~74 | 묶음 제안이나 보조 아이디어로 활용 |
| C | 60~67 | 근거나 효과를 보강해야 함 |
| D | 60 미만 | 보류. 효과가 작거나 근거가 약함 |

## 공통 감점·가점 원칙
- 원본이 '조사 설계안'이므로 효과를 실측하지 않았다는 이유로 일괄 감점하지 않는다. 대신 근거가 얼마나 최근이고 구체적인지로 ①을 차등한다.
- 시가 이미 같은 조치를 했을 가능성이 원본에 언급된 경우 ①과 ④에서 감점한다.
- 같은 주제(폭염 그늘, 통학 안전, 육아 등)의 아이디어는 개별 점수는 따로 매기고, scoreboard에서 묶음 제안 후보로 표시한다.

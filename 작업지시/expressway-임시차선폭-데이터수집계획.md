# 데이터 수집 계획: 공사 임시 차선 폭 급변 지점 탐지

짝 문서: `expressway-임시차선폭-아이디어설명.md`
원칙: **실제 데이터를 못 구해도 시연이 끝까지 되게** 단계별로 설계한다. 각 단계의 출처·접근 가능성은 아래 표의 "확인 필요"를 먼저 해소한다. 확인하지 않은 것을 확인된 것처럼 쓰지 않는다.

## 1. 필요한 데이터
| 데이터 | 용도 | 최소 규모 | 접근 난이도 |
|---|---|---|---|
| 차로 통제 도면(공사 유형별 표준 도면 + 현장별 승인 도면) | 기준 유효 폭 | 유형 5종 이상 | 중~높음(내부) |
| 공사 구간 영상(점검차·순찰차·CCTV) | 시설 분할·폭 계산 | 구간 20개, 주·야 | 높음(내부, 협약) |
| 점군/LiDAR 또는 스테레오 영상 | 정확한 폭 측정 | 구간 5개 | 높음 |
| 현장 실측(줄자·레이저 거리계) | 정답값 | 지점 100개 이상 | 중(현장 접근·안전) |
| 공사장 교통관리 기준 문서 | 폭 기준·유도시설 규정 | 문서 1~2개 | 낮음(공개 여부 확인) |
| 공사 구간 사고 기록 | 가설 검증(선택) | 가능한 만큼 | 높음 |

## 2. 단계별 수집 경로 (A → D 순으로 시도)
### A. 공개 자료 (바로 시작, 확인 필요 표시)
- 공사장 교통관리 기준·표준 도면: 한국도로공사 공개 자료실, 국토교통부 지침, 공공데이터포털 검색. **실제 공개 여부와 위치는 아직 확인하지 않았다.** 첫 작업으로 검색해 목록을 `data/sources.md`에 남긴다.
- 논문: 한국ITS학회·KoreaScience의 공사구간 사고·이동공사 연구(공개 PDF). 임계 폭·사고 요인 정리에 쓴다.
- 공개 도로 영상: ITS 국가교통정보센터 등 공개 CCTV는 **이용 조건(저장·재배포 제한)을 먼저 확인**한다. 폭 측정에는 해상도·각도가 부족할 가능성이 크므로 "시설 분할 시험용"으로만 쓴다.
- 사고 보도: 공사 구간 추돌 기사(경인일보 2024-12 등)는 범주 근거로만 인용한다.

### B. 합성·모형 데이터 (A와 병행, 주력 시연용)
- **도면 합성**: 직선 3차로를 1~2차로로 줄이는 전환부를 파라미터(전환 길이, 최소 폭, 콘 간격)로 생성. 급변·완만 두 부류를 일부러 만든다.
- **영상 합성**: 게임엔진(CARLA 등 공개 시뮬레이터)이나 3D 장면에서 콘·방호벽을 배치해 주/야·비·역광 영상과 **정확한 폭 정답**을 함께 생성한다. 시뮬레이터 라이선스·설치는 확인한다.
- **축소 모형 실측**(선택): 주차장·교정에서 콘으로 임시 차로를 만들고 드론·차량 블랙박스로 촬영, 줄자로 정답 측정. 사유지·허가된 장소에서 안전 확보 후 진행.

### C. 현장 소규모 실측 (허가 시)
- 대상: 한국도로공사 또는 시공사가 허가한 공사 구간. **개인이 임의로 고속도로 구간에 들어가 촬영·측정하지 않는다.** 안전 문제와 법적 문제가 있다.
- 방법: 점검차 영상 제공 + 담당자 입회 실측. 지점 간격 5m, 전환부 집중.

### D. 기관 협약 데이터 (최종 단계, 공모전 이후 가능성)
- 통제 도면, 점검차 영상, 시설 대장, 사고 기록. 제안서에는 "협약 시 제공 요청 항목"으로 목록화한다.

## 3. 라벨링과 정답
- 정답값: 지점별 실측 유효 폭(cm), 급변 여부(사람이 두 명 이상 독립 표기, 불일치는 합의).
- 급변 기준은 실험 전에 정한다(예: 10m당 폭 감소 X cm 이상). 기준은 공사장 교통관리 기준 문서와 선행 연구에서 가져오고, 근거를 `docs/threshold.md`에 쓴다. 결과를 본 뒤 기준을 바꾸지 않는다.
- 가려진 지점은 "판단 불가"를 별도 라벨로 둔다.

## 4. 데이터 구조
```
data/
  sources.md            # 출처, 접근 조건, 이용 허가 상태
  drawings/             # 도면(원본, 읽은 폭 CSV)
  synthetic/            # 합성 장면·영상·정답
  field/                # 허가된 실측(위치는 식별 최소화)
  labels/width_gt.csv   # point_id, station_m, width_cm, abrupt, occluded
```
- 영상에 사람 얼굴·차량 번호판이 찍히면 비식별 처리하거나 저장하지 않는다.

## 5. 수집 순서와 일정 (예: 4주)
| 주 | 작업 | 산출물 |
|---|---|---|
| 1 | A 공개 자료 목록 조사, 기준 문서 확인, 급변 기준 초안 | sources.md, threshold.md |
| 1~2 | B 합성 도면·영상 생성기 | 합성 장면 200개 이상 |
| 2~3 | 폭 계산·분할 베이스라인, 합성 평가 | 오차·탐지율 표 |
| 3 | C 소규모 실측 요청서 작성·기관 문의(허가 시 진행) | 문의 기록 |
| 4 | 제안서 정리, D 협약 요청 항목 목록 | 제안서, 요청 목록 |

## 6. 윤리·법·안전 체크리스트
- [ ] 공개 영상의 이용 조건 확인 후 사용 (저장·재배포 금지 조건 준수)
- [ ] 현장 촬영·측정은 기관 허가와 안전관리자 입회 하에서만
- [ ] 영상의 개인정보(얼굴·번호판) 비식별
- [ ] 모든 합성 데이터에 "합성" 표기, 실제 성능으로 오인될 표현 금지

## 7. 리스크와 대안
| 리스크 | 대안 |
|---|---|
| 실제 영상·도면 접근 불가 | B 합성 + 축소 모형 실측으로 시연하고, 실데이터 검증은 향후 계획으로 명시 |
| 합성↔실제 격차 | 격차를 한계로 서술하고, 소규모 실측(C)으로 보정 |
| 급변 기준의 근거 부족 | 선행 연구·기준 문서 인용, 민감도(기준값 변화) 표 제시 |
| 사고와의 인과 불명 | 인과 주장 없이 "점검 후보 탐지" 도구로 한정 |

## 8. Claude Code에게
- 이 문서와 짝 문서를 읽고 `data/sources.md` 작성(A 조사)과 B 합성 생성기부터 시작한다.
- 출처의 접근 가능 여부를 직접 확인하지 못했으면 "미확인"으로 적는다.
- 현장 접근·기관 접촉이 필요한 단계(C·D)는 실행하지 말고 사용자에게 질문하거나 문의 초안만 만든다.

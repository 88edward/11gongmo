# AFPK 영 플래너 챌린지 · 61회차 · 2026년 11월 4일

B안 가상 고객용 교육 기획이다. 모든 금액·가격·계약 조건은 가정이다. AI는 자료 구조화와 설명을 보조하고 계산은 규칙으로 검증한다.

## 1. 달마다 다른 날짜 수를 반영한 하루 예산

- **시민 불편** 월 생활비를 항상 30일로 나누면 긴 달의 마지막 날에 부족할 수 있다.
- **구체화 과정** 가상 월 예산 310,000원을 31일에 나누면 하루 10,000원이다. 30일 기준 약 10,333원씩 31일 쓰면 약 10,323원 초과한다. 정수 배분은 하루 10,000원으로 계산하고 고정 지출은 먼저 제외한다.
- **AI 적용** 가계부에서 고정·일상 지출 후보를 분류한다. 고객 확인 후 실제 달력 일수와 남은 예산으로 일별 배분을 계산한다.
- **데이터 제공 후보와 검증** 고객 제공 합성 가계부·월 예산이 주 데이터다. 금융감독원 공개 교육 자료는 설명 참고 후보다. 28·29·30·31일과 월중 시작의 합계 보존을 검증한다.

## 2. 묶음 배송의 분할 도착과 중복 구매 방지

- **시민 불편** 주문 일부만 도착했는데 전체 배송 완료로 오해하면 빠진 물건을 다시 살 수 있다.
- **구체화 과정** 주문 품목별 결제·배송·도착 상태를 나란히 정리한다. 미도착 품목은 판매자 확인 대상으로 표시하고 대체 구매 전 이미 결제한 금액을 보여준다.
- **AI 적용** 주문서·배송 안내에서 품목과 운송 단위를 추출해 연결한다. 도착 상태는 고객 확인이나 공식 배송 상태에 따르며 추정 확정하지 않는다.
- **데이터 제공 후보와 검증** 고객 동의 기반 합성 주문·배송 기록과 판매자 공식 안내가 후보다. 분할 배송 매칭 정확도와 중복 구매 건수를 평가한다.

## 3. 정산서의 마이너스 표기를 환불로 읽기

- **시민 불편** 환불·할인·취소가 음수로 표시된 장부를 일반 지출로 더하면 총액이 틀릴 수 있다.
- **구체화 과정** 가상 지출 50,000원과 환불 -10,000원이 있으면 순지출은 40,000원이다. 음수 부호가 괄호나 별도 열로 표시된 경우도 같은 결과인지 확인한다.
- **AI 적용** 문서 표 구조 인식과 항목 분류로 부호의 의미를 추출한다. 원문 셀과 계산 결과를 연결하고 모호한 표시를 고객에게 확인한다.
- **데이터 제공 후보와 검증** 고객 제공 합성 정산서·가상 거래내역을 사용한다. 서로 다른 부호 표기, 취소선과 중복 환불의 계산 정확도를 검증한다.

## 4. 단체 예약의 보증금과 이용료 입금 계좌 구분

- **시민 불편** 보증금과 이용료가 다른 항목으로 청구되면 총액을 한 번만 보내거나 중복 납부할 수 있다.
- **구체화 과정** 가상 이용료 120,000원·반환 예정 보증금 50,000원은 초기 필요자금 170,000원이다. 항목별 납부·확인 상태를 기록하고 보증금 반환 완료 후 순비용을 다시 보여준다.
- **AI 적용** 안내문에서 항목·금액·입금 목적을 추출한다. 계좌 진위는 기관 공식 창구에서 확인하고 AI가 계좌를 생성하거나 수정하지 않는다.
- **데이터 제공 후보와 검증** 고객 제공 가상 공공시설 예약 안내·합성 입금 기록이 후보다. 기관 공식 예약 조건을 실제 적용 때 확인한다. 항목 누락·중복 납부·부분 반환 계산을 검증한다.

## 5. 잔돈을 모은 금액과 실제 지출 절약 구분

- **시민 불편** 잔돈 자동저축을 소비 감소로 생각하면 생활비를 줄였다고 오해할 수 있다.
- **구체화 과정** 가상 구매 7,500원과 별도 잔돈저축 500원은 계좌에서 총 8,000원이 빠지지만 소비는 7,500원이고 자산 이동은 500원이다. 계좌 현금흐름과 소비 합계를 따로 표시한다.
- **AI 적용** 거래 관계 분류로 구매와 자동이체를 연결한다. 사용자 확인 후 내부 계좌 이동을 소비에서 제외하고 잔액 계산에는 반영한다.
- **데이터 제공 후보와 검증** 고객 제공 합성 계좌내역·자동저축 설정이 후보다. 실제 금융기관 연결은 동의와 제공 조건을 확인한다. 이체 중복 집계와 소비 과대·과소계상을 평가한다.

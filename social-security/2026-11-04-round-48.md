# 사회보장 데이터 AI 혁신 · 48회차 · 2026년 11월 4일

기존 최초 수상작 조사 결과를 재사용하는 48회차 제안이다. 아래 불편은 현장 확인 전 가설이다. 데이터 제공 기관은 협력 후보이며, 개인별 복지 기록은 권한과 동의를 확인한 뒤 최소 범위로 처리한다.

## 1. 복지관 셔틀의 짐칸까지 예약하기

- **시민 불편** 보행기를 쓰는 주민이 좌석은 예약했지만 보행기를 실을 공간이 없어 승차를 포기할 수 있다.
- **구체화** 예약 때 접은 보행기의 치수와 적재 지원 필요 여부를 선택하게 한다. 차량별 실제 적재 공간과 이미 예약된 보조기기를 대조해 담당자가 차량 또는 시간을 조정한다. 탑승자 체중 같은 불필요한 정보는 받지 않는다.
- **AI 적용** 동의받은 보조기기 사진에서 종류와 접힘 상태를 분류하고 치수 입력 누락을 감지한다. 적재 가능 여부는 실측 치수 기반 제약 최적화로 검토하고 운전자가 확정한다.
- **데이터 제공 후보와 검증** 지자체 복지관의 차량 제원·운행표·익명 승차 거절 사유, 보조기기센터의 제품 치수를 협약으로 확보한다. 실제 적재 실험에서 예측 오류와 승차 포기율을 측정한다.

## 2. 시각장애인에게 서명란 위치까지 전달하기

- **시민 불편** 음성으로 신청 내용을 들어도 마지막 서명란을 찾기 어려워 제출 단계에서 도움이 끊길 수 있다.
- **구체화** 전자서식에서 서명이 필요한 페이지와 항목을 먼저 안내하고, 현장에서는 직원에게 서명 위치 지원 요청을 연결한다. 종이서식은 서명 안내용 별도 큰 글씨·촉각 보조판으로 대응한다.
- **AI 적용** 문서 레이아웃 모델로 서명란을 검출하고 필수 서명과 선택 동의 서명을 분리한다. 서식 버전이 달라지면 직원 확인을 거쳐 안내 정보를 갱신한다.
- **데이터 제공 후보와 검증** 한국사회보장정보원과 지자체의 공개 신청서, 장애인복지관의 동의 기반 사용성 평가를 활용한다. 서명란 누락률, 독립적인 항목 탐색 성공률을 비교한다.

## 3. 세탁 지원에서 개인 옷을 되찾는 마지막 단계

- **시민 불편** 공동 세탁 후 비슷한 옷이 섞이면 주민이 자기 옷을 찾기 어렵고 분실 문의가 반복될 수 있다.
- **구체화** 접수 시 세탁망 단위 익명 표식을 붙이고 수량을 함께 확인한다. 반납 전에 접수 사진과 세탁 후 사진을 대조해 불일치 묶음만 직원이 검수한다. 얼굴·실명은 촬영하지 않는다.
- **AI 적용** 의류의 색·형태 임베딩으로 같은 묶음의 전후 품목을 매칭한다. 색이 변하거나 접혀 보이지 않는 옷은 확인 필요로 남기고 임의로 소유자를 정하지 않는다.
- **데이터 제공 후보와 검증** 지자체 이동세탁 사업자와 사회복지관의 동의받은 물품 사진·수량 기록을 사용한다. 누락 발견률과 잘못된 반납률, 검수 시간을 측정하고 사진 보관기간을 제한한다.

## 4. 다른 프로그램에 같은 이름으로 등록된 주민 확인

- **시민 불편** 동명이인의 출석이나 수령 기록이 섞이면 실제 참여자가 다음 지원 안내에서 누락될 수 있다.
- **구체화** 기관 내부의 기존 이용자 식별키를 유지하면서 같은 이름의 기록이 합쳐지려 할 때 담당자에게 경고한다. 이용자에게는 필요한 항목만 재확인하고 임의 병합을 막는다.
- **AI 적용** 확률적 레코드 매칭으로 연락처 변경·오탈자·동명이인 가능성을 구분한다. 식별키가 다른 기록을 합치는 작업은 권한 있는 담당자 확인 뒤 수행한다.
- **데이터 제공 후보와 검증** 복지관의 접근 통제된 이용자 등록·변경 이력을 협약으로 이용한다. 합성 동명이인 데이터로 먼저 시험한 뒤 잘못된 병합과 중복 안내를 각각 평가한다.

## 5. 냉장고가 고장 난 가정의 식품꾸러미 전달 조정

- **시민 불편** 냉장 보관이 필요한 식품을 받아도 냉장고가 고장 나 있으면 보관하기 어려울 수 있다.
- **구체화** 주민이 직접 보관 제약과 수리 예상일을 알리면, 담당자가 상온 보관 가능한 구성 또는 소량 분할 전달을 확인한다. 식품별 보관 기준과 실제 배송 조건을 함께 점검한다.
- **AI 적용** 포장표시 OCR로 보관 조건을 추출하고 승인된 식품 목록을 검색해 후보를 제시한다. 알레르기·유통 조건은 규칙으로 검증하며 대체품은 담당자가 확정한다.
- **데이터 제공 후보와 검증** 식품의약품안전처의 공개 식품 표시 자료, 푸드뱅크와 지자체의 협약 물품 재고·배송 기록을 후보로 둔다. 수령 거절과 폐기 신고, 잘못 읽은 보관 조건을 검증한다.

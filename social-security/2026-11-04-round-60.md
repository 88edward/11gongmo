# 사회보장 데이터 AI 혁신 · 60회차 · 2026년 11월 4일

최초 수상작 조사 결과를 재사용한다. 시민 불편은 현장 검증 전 가설이다. 기관은 데이터 제공 후보이며 개인 자료는 동의와 권한을 확인해 최소 범위로 처리한다.

## 1. 봉투 속 여러 안내문의 우선 행동 표시

- **시민 불편** 서로 다른 복지 안내를 한꺼번에 받으면 무엇부터 해야 하는지 몰라 회신을 놓칠 수 있다.
- **구체화 과정** 각 안내의 주민 행동·기한·담당 창구를 한 장에 정리한다. 정보 제공만 하는 문서와 회신이 필요한 문서를 구분하고 담당자가 우선순위를 검수한다.
- **AI 적용** 문서 분류와 행동 문장 추출로 해야 할 일 후보를 찾는다. 날짜와 창구는 원문 근거를 연결하며 불확실한 항목은 확인 대상으로 남긴다.
- **데이터 제공 후보와 검증** 지자체 복지부서 공개 안내문·합성 발송 묶음과 동의 기반 사용성 시험이 후보다. 회신 누락률, 행동 항목 추출 정확도와 안내 이해도를 평가한다.

## 2. 방문 지원의 신분 확인 방법을 미리 안내

- **시민 불편** 처음 오는 지원 인력을 어떻게 확인해야 할지 몰라 주민이 문을 열기 망설일 수 있다.
- **구체화 과정** 기관이 확정한 방문일과 공식 확인 절차를 주민이 선택한 방식으로 안내한다. 현장에서는 기관 대표 창구를 통한 확인 경로를 제공하고 변경 방문도 갱신한다.
- **AI 적용** 안내문에서 기관명·방문 목적·확인 방법의 누락을 탐지한다. 신원 인증은 기관의 검증된 시스템이 담당하며 AI가 신분 진위를 판정하지 않는다.
- **데이터 제공 후보와 검증** 지자체 방문지원기관의 승인 안내 양식·협약 일정 상태와 합성 문의 문장이 후보다. 확인 절차 이해도, 확인 지연과 잘못된 방문 안내를 검증한다.

## 3. 복지관 공용 프린터의 남은 주민 문서 확인

- **시민 불편** 인쇄 도중 용지가 떨어져 출력이 늦게 재개되면 주민 서류가 뒤늦게 배출구에 남을 수 있다.
- **구체화 과정** 출력 작업을 임시 식별번호로 관리하고 지연 재개 시 직원에게 회수 확인을 요청한다. 주민이 떠난 작업은 기관의 승인된 보관·폐기 절차로 처리한다.
- **AI 적용** 장치 이벤트의 이상 패턴으로 지연 출력 후보를 찾는다. 문서 내용과 얼굴을 수집하지 않고 출력 상태와 회수 여부만 사용한다.
- **데이터 제공 후보와 검증** 복지관·지자체 창구의 협약 프린터 로그·회수 상태 기록이 후보다. 미회수 출력물 건수, 오경고와 정상 출력 지연을 평가한다.

## 4. 프로그램 준비물의 집에 있는 대체품 확인

- **시민 불편** 지정된 준비물 이름을 보고 새로 구매했지만 집에 있는 물품으로도 참여할 수 있었던 경우가 생길 수 있다.
- **구체화 과정** 강사가 승인한 필수 기능·규격과 대체 가능 품목을 함께 안내한다. 주민이 선택한 물건은 수업 전 확인해 불필요한 구매를 줄인다.
- **AI 적용** 준비물 설명에서 기능과 규격을 추출해 승인된 대체품 목록을 검색한다. 위험 도구나 알레르기 관련 재료는 담당자가 별도 검토한다.
- **데이터 제공 후보와 검증** 복지관·평생학습관의 강사 승인 목록과 제조사 공개 규격이 후보다. 대체품 적합률, 불필요한 구매액과 당일 준비물 부족을 검증한다.

## 5. 복지시설 복도 안내의 층 번호 혼동 줄이기

- **시민 불편** 연결 통로를 지나 층 표기가 달라지는 건물에서는 주민이 상담실 층을 잘못 찾을 수 있다.
- **구체화 과정** 건물별 층 체계와 연결 통로를 하나의 경로도로 표현한다. 안내문에 출입 건물·통로·도착 층을 순서대로 보여주고 현장 표식과 맞춘다.
- **AI 적용** 실내 도면 분석과 안내판 OCR로 층 명칭을 연결한다. 실제 통행 가능한 경로와 접근성은 직원 실측으로 확인한다.
- **데이터 제공 후보와 검증** 지자체 복합복지시설의 승인 도면·허가된 안내판 사진과 동의 기반 이동 시험이 후보다. 잘못된 층 방문률과 상담실 도착시간을 평가한다.

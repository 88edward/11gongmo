# 사회보장 데이터 AI 혁신 · 56회차 · 2026년 11월 4일

최초 수상작 조사 결과를 재사용한다. 시민 불편은 현장 검증 전 가설이며 기관은 데이터 제공 후보다. 개인 자료는 동의와 접근 권한을 확인해 최소 범위로 처리한다.

## 1. 복지 상담의 여러 질문을 끝까지 확인하기

- **시민 불편** 한 번에 여러 어려움을 말한 주민이 상담 후 일부 질문에 답을 받지 못한 사실을 뒤늦게 알 수 있다.
- **구체화 과정** 상담 시작 때 주민이 원하는 질문 목록을 함께 만들고 종료 전에 답변 완료·추가 확인·다른 창구 연결 상태를 확인한다. 각 미완료 항목에 담당자와 다음 확인 방법을 붙인다.
- **AI 적용** 동의받은 상담 내용에서 질문 단위를 추출하고 답변과 의미적으로 연결한다. AI가 완료로 판단한 항목도 상담사와 주민이 확정한다.
- **데이터 제공 후보와 검증** 지자체 복지창구의 합성 상담 대본과 동의 기반 시험 기록이 후보다. 질문 누락률, 불필요한 재문의와 상담 종료 확인 시간을 평가한다.

## 2. 이동 목욕 지원 차량의 주차 공간 사전 확인

- **시민 불편** 방문 차량이 도착해도 진입 높이나 정차 공간이 맞지 않으면 주민이 서비스를 받지 못할 수 있다.
- **구체화 과정** 예약 때 차량 제원과 현장 진입·정차 조건을 대조한다. 불확실한 장소는 담당자가 사전 확인하고 대체 정차와 안전한 이동 가능성을 주민과 협의한다.
- **AI 적용** 허가된 현장 사진에서 높이 제한 표지와 장애물을 검출한다. 실제 치수·경사·이동 가능성은 실측과 담당자 확인으로 결정한다.
- **데이터 제공 후보와 검증** 지자체 방문 지원기관의 차량 제원·협약 방문 실패 기록·동의받은 현장 사진이 후보다. 당일 서비스 취소율과 사전 점검 오판 비율을 평가한다.

## 3. 복지관 강좌 재료의 촉감 선호 확인

- **시민 불편** 같은 활동 재료라도 촉감이 불편한 주민은 참여 도중 활동을 포기할 수 있다.
- **구체화 과정** 등록 때 선호하는 촉감과 대체 재료 필요 여부를 본인이 선택하게 한다. 강사가 활동 목적을 유지하는 대체 재료를 확인하고 수업 전 소량으로 시험한다.
- **AI 적용** 재료 설명과 익명 만족도 응답을 임베딩으로 묶어 대체 후보를 검색한다. 건강 상태를 추정하지 않고 이용자 선택과 강사 승인을 따른다.
- **데이터 제공 후보와 검증** 복지관·장애인복지관의 재료 목록·동의 기반 평가, 제조사 공개 재료 정보가 후보다. 중도 참여 중단률과 대체 재료 만족도를 검증한다.

## 4. 복지물품 인계 때 영문 모델명 읽기 지원

- **시민 불편** 물품의 영문 모델명이나 복잡한 기호를 읽기 어려우면 고장 문의 때 다른 제품으로 접수될 수 있다.
- **구체화 과정** 물품 인계 시 큰 글씨의 모델명·사진·기관 내부 물품번호가 담긴 카드를 제공한다. 전화 문의 때 물품번호로 제품을 확인한다.
- **AI 적용** 라벨 OCR로 모델명 후보를 읽고 등록된 물품 사진과 대조한다. 담당자가 확정한 모델명만 카드에 넣고 개인정보는 제외한다.
- **데이터 제공 후보와 검증** 복지관·보조기기센터의 협약 물품 대장과 제조사 공개 제품 사진이 후보다. 잘못된 제품 접수율과 문의 중 모델 확인 시간을 평가한다.

## 5. 주민이 선택한 읽기 속도를 유지하는 음성 안내

- **시민 불편** 안내를 느리게 듣고 싶은 주민이 매번 재생 속도를 다시 설정해야 하면 이용을 중단할 수 있다.
- **구체화 과정** 공용 기기는 현재 이용 중에만 속도와 반복 구간을 유지하고 종료 시 초기화한다. 개인 기기는 본인이 동의한 설정만 저장한다.
- **AI 적용** 문장 경계를 분석해 의미 단위로 끊어 읽고 어려운 문장의 반복 후보를 제공한다. 주민이 속도와 반복을 직접 선택한다.
- **데이터 제공 후보와 검증** 한국사회보장정보원·지자체 공개 안내문과 동의받은 사용성 시험이 후보다. 내용 이해도, 재설정 횟수와 공용 기기의 설정 초기화 성공률을 검증한다.

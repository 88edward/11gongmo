# 사회보장 데이터 AI 혁신 · 55회차 · 2026년 11월 4일

최초 수상작 조사 결과를 재사용한다. 시민 불편은 현장 검증 전 가설이며 기관별 자료는 제공 후보다. 개인 자료는 동의와 접근 권한을 확인해 최소 범위로 사용한다.

## 1. 사라진 복지 안내 첨부파일의 대체 경로 찾기

- **시민 불편** 안내문은 남아 있지만 신청서 첨부파일이 삭제되면 주민이 어디서 서식을 받아야 할지 모를 수 있다.
- **구체화 과정** 공식 안내문과 첨부 목록을 주기적으로 대조한다. 접근 실패가 확인되면 담당자가 승인한 최신 서식 경로를 안내문에 연결하고 변경 이력을 남긴다.
- **AI 적용** 문서 제목·서식 번호·버전의 의미 매칭으로 대체 후보를 찾는다. 접근 여부는 실제 응답 검사로 확인하고 최신성은 담당자가 확정한다.
- **데이터 제공 후보와 검증** 한국사회보장정보원·지자체 공개 공지와 서식 목록이 후보다. 잘못된 대체 연결률, 첨부 복구 시간과 서식 문의 건수를 평가한다.

## 2. 신청서 날짜의 작성일과 발생일 구분하기

- **시민 불편** 비슷한 날짜 칸에 작성일과 사건 발생일을 바꿔 적으면 보완 요청이 생길 수 있다.
- **구체화 과정** 날짜 칸마다 무엇의 날짜인지 짧은 예시를 보여준다. 같은 날짜가 반복되거나 시간 순서가 맞지 않으면 해당 항목만 주민에게 확인한다.
- **AI 적용** 서식 레이아웃·문항 의미 분석으로 날짜 역할을 분류한다. 시간 순서 규칙은 지침에 맞춰 적용하고 날짜가 같다는 이유만으로 오류를 확정하지 않는다.
- **데이터 제공 후보와 검증** 지자체 공개 신청서·승인 작성 지침과 합성 작성본을 사용한다. 역할 혼동 탐지율, 과도한 확인 요청과 보완 횟수를 검증한다.

## 3. 공동 급식의 쟁반을 놓고 잠깐 쉬는 위치

- **시민 불편** 보행 보조기기를 사용하는 주민이 쟁반을 든 채 대기하다 중간에 내려놓을 곳을 찾기 어려울 수 있다.
- **구체화 과정** 배식대부터 좌석까지의 동선을 관찰해 쟁반 임시 거치가 필요한 지점을 찾는다. 통로 폭과 직원 지원 동선을 확인해 거치대를 시험 설치한다.
- **AI 적용** 비식별 동작 분석으로 정지·손 바꾸기·도움 요청 후보를 집계한다. 거치 위치는 제약 최적화로 비교하고 이용자와 직원이 확정한다.
- **데이터 제공 후보와 검증** 복지관 급식시설의 도면·허가된 시험 영상·동의 기반 이용자 평가가 후보다. 쟁반 이동 성공률, 대기시간과 통로 방해를 함께 측정한다.

## 4. 전화 상담에서 잘못 받아 적은 숫자 재확인

- **시민 불편** 담당 부서 전화번호나 접수번호를 음성으로만 들으면 한 자리를 놓쳐 다시 전화해야 할 수 있다.
- **구체화 과정** 상담 종료 전 숫자를 짧은 묶음으로 읽어주고 주민이 확인한 방식으로 전달한다. 문자 수신을 원하지 않으면 상담 중 되읽기로 확인한다.
- **AI 적용** 음성 인식으로 전달한 번호와 되읽은 번호의 차이를 탐지한다. 주민의 번호를 자동 수정하지 않고 상담원이 불일치 부분을 확인한다.
- **데이터 제공 후보와 검증** 지자체 상담창구의 합성 통화 대본과 동의받은 시험 녹음이 후보다. 숫자 오기 탐지율, 재문의와 상담 추가 시간을 평가한다.

## 5. 대여 물품 설명서의 실제 버튼 배열 맞추기

- **시민 불편** 같은 이름의 기기라도 모델별 버튼이 달라 안내 그림을 따라 하기 어려울 수 있다.
- **구체화 과정** 기기 모델 식별 후 해당 버전 설명서의 버튼 그림을 제공한다. 현장 사진과 그림을 대조해 다른 모델의 안내가 붙은 경우 담당자가 교체한다.
- **AI 적용** 모델 라벨 OCR과 버튼 배치 이미지 매칭으로 안내 일치 여부를 검사한다. 기능·조작 순서는 제조사 원문을 따른다.
- **데이터 제공 후보와 검증** 보조기기센터·제조사의 이용 허가된 모델별 설명서와 대여 기기 사진이 후보다. 잘못된 설명서 연결률과 사용 시작 단계의 도움 요청 건수를 검증한다.

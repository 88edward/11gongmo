# 사회보장 데이터 AI 혁신 · 58회차 · 2026년 11월 4일

최초 수상작 조사 결과를 재사용한다. 아래 불편은 현장 검증 전 가설이다. 데이터 제공 후보 기관과 확보 조건을 확인해야 하며 개인 자료는 동의와 권한을 확인해 최소한으로 처리한다.

## 1. 인쇄된 복지 안내의 잘린 마지막 줄 확인

- **시민 불편** 큰 글씨로 확대 인쇄한 안내에서 마지막 줄이나 연락처가 잘리면 주민이 다음 행동을 알기 어렵다.
- **구체화 과정** 원문과 출력 미리보기를 비교해 필수 정보가 남아 있는지 확인한다. 잘린 부분은 페이지를 늘리거나 문단을 재배치해 담당자가 검수한다.
- **AI 적용** 문서 레이아웃 분석과 OCR 정합으로 원문 항목의 출력 누락을 찾는다. 날짜·연락처·제출처는 별도 필수 항목으로 검사한다.
- **데이터 제공 후보와 검증** 한국사회보장정보원·지자체 공개 안내문과 자체 시험 출력물이 후보다. 필수 항목 누락 탐지율과 큰 글씨 이용자의 안내 이해도를 검증한다.

## 2. 복지관 프로그램의 출석 확인 방식 선택

- **시민 불편** 이름을 큰 소리로 부르는 출석 확인이 부담스럽거나 음성 호출을 듣기 어려운 주민이 있을 수 있다.
- **구체화 과정** 등록 때 이름 호출·개별 번호·직원에게 직접 확인 중 선호 방식을 선택한다. 강사는 확인 여부만 보고 누락자를 조용히 재확인한다.
- **AI 적용** 비식별 출석 이벤트를 분석해 특정 확인 방식에서 반복되는 누락을 찾는다. 선호 방식은 주민이 직접 정하며 음성·얼굴로 신원을 추정하지 않는다.
- **데이터 제공 후보와 검증** 복지관·가족센터의 협약 출석 상태와 동의받은 선호 설문이 후보다. 출석 누락률, 재호출 횟수와 이용자 불편 설문을 평가한다.

## 3. 지원 물품의 조립 공구를 수령 전에 확인

- **시민 불편** 가구 지원을 받아도 필요한 공구가 없어 조립을 미루면 물품을 활용하기 어렵다.
- **구체화 과정** 물품별 제조사 조립 목록과 가정에서 준비 가능한 공구를 대조한다. 담당자가 공구 대여 또는 조립 지원 가능 여부를 함께 안내한다.
- **AI 적용** 설명서에서 공구 종류·규격을 추출하고 승인된 대여 목록과 의미 매칭한다. 실제 조립 가능성과 안전한 사용은 담당자가 확인한다.
- **데이터 제공 후보와 검증** 지자체 주거복지센터·복지관의 협약 공구 재고와 제조사 사용 허가 설명서가 후보다. 수령 후 미조립 기간과 공구 규격 오안내율을 검증한다.

## 4. 동의 철회가 반영된 홍보물 배포 확인

- **시민 불편** 사진 사용 동의를 철회했는데 이미 만든 홍보 초안에 사진이 남아 있으면 주민이 반복해서 삭제를 요청할 수 있다.
- **구체화 과정** 사진 자산에 동의 식별키와 이용 범위를 연결한다. 배포 전 철회 상태를 대조해 해당 자산을 포함한 초안을 담당자 검토 대상으로 보낸다.
- **AI 적용** 자산 해시와 유사 이미지 검색으로 잘리거나 크기가 바뀐 사진의 사용 후보를 찾는다. 얼굴 신원 추정 없이 등록 자산과의 일치만 검사한다.
- **데이터 제공 후보와 검증** 복지관의 권한 통제된 동의 기록·홍보 자산 목록이 후보다. 합성 인물 자료로 먼저 시험하고 철회 자산 잔존율과 무관한 자산 오검출을 평가한다.

## 5. 복지 안내에서 서로 다른 제출처 주소 구분

- **시민 불편** 신청서를 보내는 주소와 문의 기관 주소가 함께 있으면 주민이 잘못된 곳으로 우편을 보낼 수 있다.
- **구체화 과정** 안내문에 우편 제출·방문 제출·문의 주소를 역할별로 분리한다. 발송용 표기에는 확정된 제출 주소와 필요한 수신 부서를 함께 보여준다.
- **AI 적용** 주소 개체 추출과 주변 문맥 분류로 제출처 역할을 연결한다. 최종 주소는 기관의 승인 목록과 대조하고 담당자가 확정한다.
- **데이터 제공 후보와 검증** 지자체 공개 공고·기관 주소 목록과 합성 문의 문장을 사용한다. 제출처 오인률, 반송 건수와 역할 분류 정확도를 평가한다.

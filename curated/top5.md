1~17회차 340개(16·17회차는 최고 7.0이라 교체 없음. 13~15회차에서 바뀐 것은 햇반 5위뿐: 15-3 농부의 한 문장이 조리 띠를 대체. 동점 예비는 evaluations/ 참고. AFPK 15-3 격주 월세 통장, 도로공사 13-1 공사 예고문 방향 지도와 11-5 전광판 글자 결손 탐지가 7.5 동점 예비) 중 냉정 평가 상위 5개씩. 평가 근거는 `evaluations/` 참고. 공고 사이트 접속 불가로 마감일·규격은 미확인.

## AFPK 영 플래너 챌린지

재무설계 6단계(범위 합의→자료 수집→진단→대안→실행→점검)로 한 사례를 끝까지 전개하는 B안 사례 보고서.

> 공고 원문 대조 필요. 사례 하나를 깊게 쓰고, AI 입력·오답·수정 근거를 부록에 남기는 것이 핵심.

### 1. 학기마다 소득이 끊기는 강사 (8.0점, 출처 1-2)
- **문제와 숫자** — 강의 달 280만 원, 방학 2달 80만 원, 생활비 월 170만 원. 방학 부족액 (170−80)×2=180만 원.
- **구체화** — ① 범위 합의: 목표를 '방학 두 달 적자 0원'으로 정의 ② 자료: 가상 강의계약·12개월 통장내역 ③ 진단: 월평균 소득이 아닌 월별 최저 잔액을 지표로 ④ 대안: 학기 6개월 월 30만 원 적립(기본), 강의 1개 취소 시 적립 45만 원 또는 지출 조정 혼합안 ⑤ 실행: 급여일 다음 날 자동이체 ⑥ 점검: 분기별 적립 달성률, 강의 수 변동 시 재계산 규칙.
- **AI 적용·검증** — AI가 계약서 문장에서 학기·방학 소득을 추출하고 소득 감소 시나리오 3개를 생성한다. 적립 합계와 인출 순서는 엑셀 수식으로 재검산하고, AI가 방학 개월 수를 틀린 사례를 부록에 기록한다.
- **데이터** — 가상 강의계약, 통계청 가계동향조사(비교용).
- **약점과 보완** — 가정이 전부 가상이라는 점. 보완: 비상예비자금 3~6개월 기준과 연결하고 건강보험 지역가입 전환 같은 제도 변수를 시나리오에 포함한다.

### 2. 간병을 교대하는 남매 (7.5점, 출처 1-3)
- **문제와 숫자** — 월 간병비 120만 원 현금과 휴직한 가족의 소득 감소(기회비용)를 구분해 6개월 분담표를 만든다.
- **구체화** — ① 범위: 부모 간병 6개월 분담 합의 ② 자료: 장기요양 등급·본인부담 안내, 두 사람의 급여 ③ 진단: 현금 지출과 소득 손실 이중 산입 여부 ④ 대안 A 동등 분담 B 소득비례 C 휴직자 보전금 ⑤ 실행: 월 정산일과 증빙 규칙 ⑥ 점검: 요양등급 변경 시 재협의.
- **AI 적용·검증** — 언어모델이 돌봄일지·영수증에서 비용 항목을 추출하고 이중 산입을 표시한다. 두 가구의 최저 잔액 비교는 수식으로 계산해 AI 값과 대조한다.
- **데이터** — 국민건강보험공단 장기요양 안내, 가상 급여·돌봄일지.
- **약점과 보완** — 법적 부양의무·상속과 경계가 흐려질 수 있다. 보완: 법률 판단은 범위 밖으로 명시하고 재무 분담만 다룬다.

### 3. 재취업 교육을 버틸 수 있는 달수 (7.5점, 출처 2-3)
- **문제와 숫자** — 준비금 800만 원−교육비 160만 원−비상금 100만 원=540만 원, 월 필수비 135만 원이면 4개월.
- **구체화** — ① 범위: 교육 기간+구직 기간 합산 목표 ② 자료: 고용24 훈련과정, 지출표 ③ 진단: '버틸 수 있는 달수'(런웨이) 산출 ④ 대안: 취업 2개월 지연 시 부족액, 훈련장려금·구직촉진 등 확정 지원만 반영 ⑤ 실행: 단계별 지출 상한 ⑥ 점검: 월 런웨이 재계산.
- **AI 적용·검증** — AI가 훈련 공고에서 지원 조건을 추출한다. 미확정 지원금은 기본 잔액에서 제외하는 규칙을 고정하고, AI가 확정으로 잘못 표시한 항목을 부록에 대조한다.
- **데이터** — 고용24 훈련 과정, 통계청 가계동향조사, 가상 지출표.
- **약점과 보완** — 제도 변수(실업급여 등)가 많다. 보완: 이번 사례는 수급 자격이 없는 경우로 한정한다.

### 4. 부부의 은퇴일이 다른 18개월 (7.5점, 출처 2-5)
- **문제와 숫자** — 필수비 250만 원, 공백기 소득 195만 원이면 월 55만 원×18개월=990만 원이 필요하다.
- **구체화** — ① 범위: 부부 중 한 사람 선퇴직 계획 ② 자료: 연금 예상액 조회값, 가계부 ③ 진단: 평균 계획에서 안 보이는 단기 적자월 ④ 대안: 퇴직 전 적립, 지출 조정, 연금 개시 시점 조정의 혼합안 ⑤ 실행: 월별 현금흐름표 ⑥ 점검: 반기 재점검.
- **AI 적용·검증** — AI가 현금흐름표에서 소득 시작월 혼동을 찾고, 연금 개시를 한 달 미룬 결과를 수식으로 교차검증한다. 6단계를 모두 전개하기 좋은 사례.
- **데이터** — 국민연금공단 예상연금 안내와 가상 조회값, 통계청 가계동향조사.
- **약점과 보완** — 연금 수치 정확성. 보완: 공식 모의계산 결과를 입력값으로 쓰고 출처를 표기한다.

### 5. 집을 줄였는데 남는 돈은 얼마인가 (7.5점, 출처 5-2)
- **문제와 숫자** — 은퇴자가 작은 집으로 옮길 때 매매 차액 5천만 원 전체를 은퇴자금으로 잡기 쉽다. 이사·수리 견적 800만 원과 확인된 채무 정산 1천만 원을 빼면 실제 가용액은 3,200만 원.
- **구체화** — ① 범위: 다운사이징 후 은퇴 현금흐름 목표 ② 자료: 가상 매각·매입 정산서, 이사·수리 견적서 ③ 진단: 차액에서 비용·채무·미확정 비용을 단계별로 차감한 가용액 ④ 대안: 전액 일시 인출 vs 연금성 분할 인출 vs 일부 재투자, 수리비 20% 상승 시나리오 ⑤ 실행: 인출 순서와 예비 자금 분리 ⑥ 점검: 확정 세금·거래비가 나오면 재계산.
- **AI 적용·검증** — AI가 견적서에서 중복·누락 항목을 표시하고 미확정 비용은 별도 범위로 둔다. 차감 합계는 수식으로 재검산하고, AI가 항목을 중복 계상한 사례를 부록에 기록한다.
- **데이터** — 국토교통부 실거래가 공개 자료, 가상 정산서·이사 견적.
- **약점과 보완** — 세금·거래비가 비어 있어 진단이 불완전하다. 보완: 양도·취득 관련 세금은 공식 모의계산 결과를 입력값으로 쓰고 출처를 표기하며, 이번 사례는 해당 조건을 고정한다.

## 사회보장 데이터 AI 혁신

공개 사업 안내로 시제품을 만들고 기관 기록은 협약 후 비식별 자료로 평가한다.

> 공고 원문 대조 필요. 공개 데이터로 시연 가능한 안을 우선했다.

### 1. 식사 배달이 비는 공휴일 (7.5점, 출처 4-1)
- **문제와 숫자** — 혼자 사는 어르신이 연휴에 배달이 쉬는지, 전날 두 끼가 오는지 알기 어렵다.
- **구체화** — 수행기관별 공지에서 날짜·끼니·대체일 추출 → 날짜별 받을 끼니 달력 → 중복·공백 표시 → 확인 안 된 칸은 담당자가 전화 점검 → 큰 글씨 달력 인쇄·음성 안내.
- **AI 적용·검증** — LLM으로 공지에서 날짜·끼니·대체일을 추출하고 달력 규칙으로 중복·공백을 검산한다. 합성 공지 100건으로 미배달 끼니 탐지율과 잘못 표시한 공백 건수를 평가.
- **데이터** — 지자체 노인급식 사업안내, 수행기관 배달계획·수령 확인(협약).
- **약점과 보완** — 배달계획 확보와 안부 확인 사업과의 중복. 보완: 시범 구 1곳·수행기관 2~3곳으로 한정하고 합성 공지로 추출 정확도부터 증명한다.

### 2. 보완 요청 쉬운말 검사 (7.5점, 출처 1-5)
- **문제와 숫자** — 보완 요청을 받은 시민이 무엇을 언제까지 어디에 내야 하는지 모른다. 발송 전 담당자용 검사 도구.
- **구체화** — 담당자가 통지문 작성 → 도구가 행동·기한·제출처 3항목을 추출해 누락을 표시 → 쉬운말 초안 생성 → 원문과 다른 기한은 규칙으로 차단 → 담당자 승인 후 발송.
- **AI 적용·검증** — LLM 추출과 규칙 기반 차단을 조합한다. 평가는 읽은 사람이 다음 행동을 맞힌 비율(원문 대비)과 담당자 수정 건수.
- **데이터** — 복지로 신청 안내, 지자체 비식별 보완 통지 예문.
- **약점과 보완** — 개인정보 없는 예문으로 시연 가능. 보완: 지자체 도입 경로(기존 통지 시스템 연계)와 쉬운 문장 가이드와의 차별을 설명한다.

### 3. 복지관 자막이 필요한 회차부터 (7.5점, 출처 5-5)
- **문제와 숫자** — 난청 이용자는 녹화 강좌를 열기 전까지 자막 누락이나 숫자 오기를 알기 어렵고, 시간·금액·주소가 틀리면 실제 피해로 이어진다.
- **구체화** — 허가받은 복지관 강의 영상·교안 → 음성인식 자막 생성 → 교안의 숫자·고유명사와 대조 → 불일치 구간을 검수 우선순위로 표시 → 담당자가 수정한 자막과 함께 게시.
- **AI 적용·검증** — 음성인식 자막과 교안 텍스트를 대조해 시간·금액·주소 오기를 찾는다. 검수 전후의 필수정보 오기율과 검수 소요시간을 비교하고, 숫자를 놓친 사례를 기록한다.
- **데이터** — 지자체 복지관 허가 강의 영상·교안, 한국사회보장정보원 복지서비스 안내 용어.
- **약점과 보완** — 자막 자동 생성 서비스가 이미 많다. 보완: 차별점을 '필수정보 우선 검수 큐'로 한정하고, 복지서비스 용어 사전을 붙여 일반 자막과 오기율을 비교한다.

### 4. 자립준비청년의 첫 집, 물품 중복 지원 줄이기 (7.5점, 출처 6-5)
- **문제와 숫자** — 입주할 때 기관 두 곳에서 같은 생활용품을 받는데 정작 필요한 물건은 빠진다.
- **구체화** — 청년이 희망 품목 체크 → 담당자가 지원 예정 꾸러미와 대조 → 중복 품목을 교환 후보로 표시 → 크기·용량이 다른 품목은 당사자 확인 → 교환안 승인 → 입주 2주 뒤 미충족 점검.
- **AI 적용·검증** — 품목 표현을 의미 매칭하고 규격이 다르면 확인으로 넘긴다. 합성 목록 200건에서 중복 탐지 재현율·잘못 교환 후보 건수, 입주 후 미충족 품목 수를 기존 방식과 비교.
- **데이터** — 아동권리보장원 자립지원 안내, 지역 자립지원전담기관 꾸러미 목록(협약), 가상 희망 목록.
- **약점과 보완** — 품목 사전+규칙으로도 되어 AI 필요성을 질문받는다. 보완: 사전 매칭 대비 의미 매칭의 추가 재현율을 수치로 비교하고, 개인정보 없는 합성 목록으로 시연한다.

### 5. 두 번 가지 않는 복지 창구 (7.0점, 출처 1-1)
- **문제와 숫자** — 가족이 대신 신청하러 갔다가 대리 서류 부족으로 재방문.
- **구체화** — 사업과 신청인 관계를 선택 → 본인 서류와 대리인 서류를 분리해 한 장으로 출력 → 공고에 없는 관계는 담당 확인으로 전환.
- **AI 적용·검증** — 공고 RAG로 근거 문장을 붙이고, 담당자 정답 대비 빠진 서류 건수를 평가한다.
- **데이터** — 복지로 서비스 안내, 지자체 신청서·위임장 서식.
- **약점과 보완** — 복지로 안내와 겹침. 보완: 대리 신청 조합에 특화한 출력물이 차별점임을 비교표로 보여준다.

## 한국도로공사 AI 활용 아이디어

고속도로 이용·운영 중 불편을 AI로 줄이는 실증 가설. 개별 운영자료는 공사 협의 대상.

> 공고 원문 대조 필요. 상위 3개는 같은 '정체 후미 선제 안내' 엔진을 공유한다.

### 1. 안개 속 속도 차가 커지는 구간 (7.5점, 출처 3-1)
- **문제와 숫자** — 평균속도가 비슷해도 속도 편차가 커지는 구간에서 급감속 군집이 생긴다.
- **구체화** — 차로별 속도 분산을 계산 → 시정 악화와 결합해 상류 전광판 안내 시점을 관제원에게 제안.
- **AI 적용·검증** — 기상과 속도 분포로 급감속 군집을 예측. 단순 안개 경보와 비교해 확보 시간과 오경보 횟수 평가.
- **데이터** — 한국도로공사 검지기·전광판 이력, 기상청 시정관측.
- **약점과 보완** — 기존 안개 경보와 차이 입증. 보완: 같은 구간 과거 안개일 재생 비교.

### 2. 겨울 아침, 교량별 제설 확인 순서 (7.5점, 출처 3-2)
- **문제와 숫자** — 그늘진 교량부터 재결빙되어 운전자가 노면 상태를 예측 못 한다.
- **구체화** — 전날 처리한 교량 중 재결빙 위험이 높은 곳을 새벽 순찰 우선 목록으로 제시. 관측 부족 구간은 별도 표시.
- **AI 적용·검증** — 노면온도·일사·처리 후 경과시간으로 위험 확률 추정. 같은 순찰거리에서 결빙 포착률 비교.
- **데이터** — 교량대장, 제설 작업일지, 기상청 일사·온습도.
- **약점과 보완** — 기존 노면온도 센서와 중복. 보완: 센서 없는 교량에 한정.

### 3. 공사구간 정체 꼬리 가변표지 앞당김 (7.5점, 출처 1-2+3-3)
- **문제와 숫자** — 공사 합류나 휴게소 진입 대기열의 꼬리가 본선으로 늘어나는데 안내가 늦다.
- **구체화** — 속도 시계열 급변점으로 후미 이동을 예측 → 표지 앞당김을 관제원에게 권고. 휴게소 진입로 대기열 길이는 같은 모듈의 입력으로 추가.
- **AI 적용·검증** — 급변점 탐지와 도달시간 범위 계산. 예고 여유시간과 허위 경보율로 평가.
- **데이터** — 작업 일정, 검지기, 진입로 도면·CCTV(협약).
- **약점과 보완** — AI가 없어도 되는지 질문을 받는다. 보완: 임계값 규칙과 비교 실험.

### 4. 졸음쉼터로 잘못 드는 역방향 차량 (7.5점, 출처 4-1)
- **문제와 숫자** — 야간 졸음쉼터 출구 쪽에서 역방향으로 움직이는 차량을 다른 운전자가 알아채기 어렵다.
- **구체화** — 도면에 허용 방향 구역 정의 → 차량 궤적과 비교 → 출구 경계 통과 시 관제 화면 알림 → 관제원이 경고 장치 작동 판단.
- **AI 적용·검증** — 궤적을 허용 방향과 비교하되 주차면의 정상 후진과 출구 경계 통과를 구분. 정상 후진 100건당 오경보와 경계 통과 후 탐지시간 측정.
- **데이터** — 한국도로공사 쉼터 도면·협약 영상, 자체 모의 궤적.
- **약점과 보완** — 사건이 드물어 검증이 모의 궤적에 한정되고 기존 역주행 감지와 차이를 물을 수 있다. 보완: 졸음쉼터 출구 한정, 정상 후진 구분 지표를 핵심으로.

### 5. 터널 비상전화의 음질 점검 (7.5점, 출처 6-4)
- **문제와 숫자** — 비상전화가 연결돼도 잡음 때문에 위치·상황을 알아듣기 어려울 수 있다. 정기 점검은 연결 여부 중심이다.
- **구체화** — 정비 시 표준 시험 문장 송신 → 수신 음질(SNR·인식 오류율) 산출 → 기준 미달 단말을 점검 우선순위로 → 회선·단말 분리 재시험 → 정비 후 재측정 기록.
- **AI 적용·검증** — SNR과 음성인식 오류율을 조합한 이상 탐지. 담당자 청취 평가와의 일치도, 불량 단말 순위 정확도로 평가.
- **데이터** — 한국도로공사 터널 비상전화 설비대장, 합성 시험 음성, 정비기록. 이용자 음성 수집 불필요.
- **약점과 보완** — 신호처리 임계값만으로 충분하다는 지적 가능. 보완: 임계값 규칙 대비 조합 지표의 불량 탐지율을 비교하고 터널 소음을 섞은 시험음으로 대표성을 확인한다.

## 햇반 30주년 AI 창작

미래 제품·생활상을 AI 이미지·영상으로 보여준다. 공식 햇반·30주년 로고 합성, 프롬프트와 편집 전후 기록 보관. 발표 예정 11월 27일.

> 공고 원문 대조 필요. 30주년과의 연결 문장을 각 작품에 넣는다.

### 1. 점자 한 칸 옆의 쌀알 (8.0점, 출처 3-3)
- **문제와 숫자** — 포장 색이 비슷해 저시력 이용자가 원하는 밥 종류를 구별하기 어렵다.
- **구체화** — 쌀밥·잡곡밥 등 세 종류를 구분하는 돌출 쌀알 패턴을 용기 테두리에 넣고, 손이 찾아가는 20초 영상으로 보여준다. 30주년 문구: '30년째 모두의 식탁'.
- **AI 적용·검증** — 매크로 참조 사진으로 영상을 생성하고 패턴 개수·배치는 합성 레이어로 고정. 촉각 모형으로 정확도·탐색 시간 비교.
- **데이터** — CJ제일제당 제품 구분, 국립국어원 점자 자료.
- **약점과 보완** — 점자 표기 규정과 정합성. 보완: 점자 대체가 아닌 보조 표식임을 명시하고 참여자 동의 확보.

### 2. 가족 레시피가 돌아오는 빈 뚜껑 (7.5점, 출처 4-5)
- **문제와 숫자** — 따로 사는 가족의 반찬 조합을 말로 전하면 기억하기 어렵다.
- **구체화** — 25초 영상: 자취방 빈 외포장 → 가족이 세 칸에 그린 반찬 그림 → 상차림 → 완성한 한 끼 사진을 돌려보냄. 30주년 문구: '30년, 밥 한 끼에 담긴 안부'.
- **AI 적용·검증** — 참여자가 직접 그린 그림을 참조로 반찬이 식탁으로 이어지는 장면을 생성하고 손글씨는 원본을 합성한다. 시청자가 세 재료와 메시지를 재구성하는지 평가.
- **데이터** — 농촌진흥청 향토음식 자료, CJ 제품 이미지, 동의받은 레시피.
- **약점과 보완** — 외포장에 그림 칸을 두는 제품 변경이 전제. 보완: 30주년 한정 슬리브로 가정하고 참여자 동의를 확보한다.

### 3. 밥알로 쓰는 식탁 초대장 (7.5점, 출처 3-4)
- **문제와 숫자** — 식사 시간이 다른 가족은 이 밥이 누구 몫인지 놓친다.
- **구체화** — 외포장 한 면이 접이식 식탁 카드가 되어 '네 몫이야' 손글씨와 다음 식사 시간을 담는 4:5 캐러셀 5컷. 30년 동안 이어진 '밥 한 끼의 마음' 서사.
- **AI 적용·검증** — 아침·저녁 참조 이미지로 같은 식탁을 변환하고 손글씨는 별도 합성해 철자를 보존. 무자막으로 관계와 메시지를 읽는지 확인.
- **데이터** — 통계청 생활시간조사, CJ 묶음 포장 사진, 동의받은 손글씨.
- **약점과 보완** — 평범한 광고 느낌. 보완: 가족 인물 대신 손과 식탁 위주 연출.

### 4. 한글 밥맛 사전 (7.5점, 출처 6-3)
- **문제와 숫자** — 한국어를 배우는 사람에게 '고슬고슬'과 '찰지다'는 번역만으로 식감 차이가 떠오르지 않는다.
- **구체화** — 4:5 캐러셀 5컷: ①단어 ②숟가락을 들면 밥알이 흩어짐(고슬고슬) ③붙어 올라옴(찰짐) ④두 종 나란히 비교 ⑤30주년 문구 '30년, 밥맛을 말하는 법'.
- **AI 적용·검증** — 실제 접사 영상을 조건으로 질감을 확대 생성하고 단어 표기는 사전과 대조해 합성. 보기 순서를 섞어 단어-질감 연결 정확도 측정.
- **데이터** — 국립국어원 한국어기초사전, 농촌진흥청 쌀 품종 설명, CJ 제품 사진.
- **약점과 보완** — 30주년 연결이 약하고 '미래 햇반 두 종' 가정이 느슨하다. 보완: 30주년 한정 '밥맛 사전 에디션'으로 서사를 고정하고 실제 밥알 접사만 근거로 쓴다.

### 5. 지금 먹는 밥을 만든 농부의 한 문장 (7.5점, 출처 15-3)
- **문제와 숫자** — 소비자는 쌀 원산지를 읽어도 그 지역에서 어떤 일을 거쳐 수확했는지 실감하기 어렵다.
- **구체화** — 20초 영상: 미래 햇반 뚜껑의 한 줄을 읽으면 논에서 물꼬를 보는 농부의 손과 식탁에서 밥을 뜨는 손이 같은 구도로 이어진다. 30주년 문구: '30년, 쌀에서 식탁까지'.
- **AI 적용·검증** — 농부가 승인한 문장만 쓰고 두 손의 동작을 연결해 생성한다. 실제 산지·발화와 합성 장면의 일치 여부를 당사자가 검수하고, 검수 기록을 제작 노트에 남긴다.
- **데이터** — 농촌진흥청 벼 재배 자료, CJ 제품 표시, 동의받은 농가 인터뷰.
- **약점과 보완** — 영상이 평이할 수 있고 농가 섭외·동의가 선행돼야 한다. 보완: 손 동작 한 컷의 연결(매치컷)에 연출을 집중하고, 섭외 불가 시 공개 허용된 인터뷰 자료로 대체한다.

# 11gongmo 냉정 평가 (2026-11-04 기준 1~61회차)

대상: social-security(사회보장 데이터 AI 혁신), afpk(영 플래너), expressway(도로공사 AI), hetbahn(햇반 30주년) 각 61회차 × 5개 = 1,220개 아이디어.

## 평가 기준 (100점)
| 항목 | 배점 | 보는 것 |
|---|---|---|
| 문제 중요도 | 25 | 실제로 많은 사람이 겪거나 사고·손실이 큰가 |
| 독창성 | 20 | 과거 수상작 유관 사례·타 회차와 겹치지 않는가 |
| AI 필연성 | 20 | AI가 없으면 안 되는가, 아니면 표·규칙·종이카드로 충분한가 |
| 실현·데이터 | 20 | 데이터가 실제로 구해지는가, 작은 시연이 가능한가 |
| 검증 가능성 | 15 | 효과를 숫자로 보일 수 있는가 |

점수 해석: 75↑ 제출 검토 / 60~74 보완하면 가능 / 60↓ 탈락권.

## 평가 범위에 대한 정직한 고지
- 58회차(4개 공모전 20개 아이디어)는 전문 읽고 항목별 채점했다. 각 공모전 파일 참조.
- 1~56회차는 1,120개 제목 전수 검토 + 24개 본문 정독 + 키워드 빈도 집계로 평가했다. 개별 본문을 전부 정독한 것은 아니다. 이후 회차는 매 회차 개별 채점 가능.
- 이후 10분 회차는 같은 기준으로 추가한다.

## 총평
1. **양산형 소재 반복이 심하다.** 도로공사 제목의 28%(79/280)가 '휴게소', 11%가 '터널'. 사회보장은 복지관·보조기기 대여·인계 소재가 계속 변주된다. 같은 구조에 소재만 바꿔 끼운 인상이다.
2. **AI가 장식인 아이디어가 많다.** "문서에서 날짜·금액을 추출하고 계산은 규칙으로" 패턴은 AFPK·사회보장에 수십 개다. 추출만 AI이고 핵심은 표·산식이라 'AI 활용' 공모 취지에서 약하다.
3. **햇반은 가장 약하다.** 광고 콘티 형식이 고정되어 '서른 개 ○○' 모티프가 최소 13개 회차에 쓰였다. 제품 매력·30주년 서사보다 '시민 불편' 틀에 끼운 느낌이 강하다.
4. **강점**: 개인정보·안전 면책이 일관되고 검증 지표가 명시된다. 허황한 수치 주장이 없다.
5. 상위권은 공통적으로 (a) 대규모 문서/신고 데이터가 이미 존재하고 (b) AI(문서 이해·군집·영상 분석)가 없으면 사람이 못 하는 규모이며 (c) 오류 시 비용(사고, 급여 누락)이 크다.

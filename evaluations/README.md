냉정 평가 원칙: 문제가 실재해도 AI가 없어도 풀리면 감점, 기관 협약이 있어야 검증되는 안은 실현성 감점, 이미 존재하는 서비스와 겹치면 차별성 감점.

- **AFPK 영 플래너 챌린지**: 고객 상황의 현실성·대표성(25) / 6단계 보고서 확장 깊이(20) / AI 활용·검증 타당성(20) / 수치 정합·자료 접근(20) / 독창성(15)

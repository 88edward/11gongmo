# 사회보장 데이터 AI 혁신 평가 (1~3회차, 15개)

**총평** — 공통 약점은 데이터다. 대부분 "지자체/기관 협약 후 비식별 자료"를 전제하는데 경진대회 기간 안에 확보 가능한지 근거가 없다. 공개 데이터만으로 시연 가능한 안을 우선해야 한다. 또 일부는 개인 위치·건강·장애 정보를 다루는데 개인정보 리스크 설명이 문장 한 줄이다. 과거 수상작(찬스링크, eye쇼핑, 에브리웨어)은 당사자 한 집단의 구체적 불편을 앱으로 푼 형태 → 여기서는 '운영자 도구'가 많아 차별점은 있으나 시민 체감 서사가 약하다.

| 회차-번호 | 아이디어 | 점수 | 판정 |
|---|---|---|---|
| 1-1 | 두 번 가지 않는 복지 창구 | 7.0 | **추천** |
| 1-2 | 돌봄 인계 달력 | 6.5 | 보류 |
| 1-3 | 복지 공고 변경표 | 6.0 | 탈락 |
| 1-4 | 방학 급식 빈 시간 지도 | 7.0 | **추천** |
| 1-5 | 보완 요청 쉬운말 검사 | 7.5 | **추천(최상)** |
| 2-1 | 바우처 시간표 | 6.5 | 보류 |
| 2-2 | 복지관 쉬운 첫 수업 | 6.5 | 보류 |
| 2-3 | 보조기기 수리 순번 | 6.5 | 보류 |
| 2-4 | 오늘 열리는 무료급식소 | 7.0 | 1-4와 병합 |
| 2-5 | 활동지원사 인계 카드 | 6.5 | 보류 |
| 3-1 | 콜백 시간 선택권 | 7.0 | **추천** |
| 3-2 | 이사 후 안부 확인 인계 | 6.5 | 보류 |
| 3-3 | 복지관 송영차 도착 | 6.0 | 탈락 |
| 3-4 | 푸드뱅크 크기 맞춤 기부 | 7.0 | **추천** |
| 3-5 | 그림으로 시작하는 상담 | 6.5 | 보류 |

## 이유
- **1-1 (7.0)** 대리 신청 재방문은 실제로 흔한 불편. 복지로 공고는 공개라 데이터 확보 쉬움. 약점: 복지로 '서비스 모의계산·서류 안내'와 겹침 → 대리인/본인 서류 분리 출력이 차별점. RAG 근거 문장+미명시 시 담당 확인 설계는 좋음.
- **1-2 (6.5)** 퇴원-돌봄 공백은 실재하지만 병원·지자체 데이터 협약이 필수이고 이미 퇴원환자 지역사회 연계 사업이 있다. 차별점 불분명.
- **1-3 (6.0)** 신·구 공고 diff는 AI 없이도 대부분 해결. AI 필요성 낮음.
- **1-4 (7.0)** 급식카드 가맹점 데이터는 공개, 보행망 도달권 계산은 AI/공간분석에 적합. 아동 체감이 큼. 약점: 영업시간 현장조사 비용, 폐점 추정 모델의 정답 데이터 부족.
- **1-5 (7.5)** 가장 현실적: 문서 한 건으로 시연 가능, 개인정보 거의 없음, 추출+규칙 차단(원문과 다른 기한 차단) 구조로 LLM 위험을 통제. 약점: 지자체가 실제 도입하는 경로 필요, 쉬운 문장 가이드 이미 존재.
- **2-1 (6.5)** 시간표는 좋으나 기관 예약 시스템 연동 협약이 사실상 어렵다.
- **2-2 (6.5)** 가치는 높지만 대상이 복지관 강좌에 국한, 그림사전 저작권 이슈.
- **2-3 (6.5)** 순서 최적화는 운영 도구로 의미 있으나 AI라기보다 스케줄링. 대여·수리대장 협약 필요.
- **2-4 (7.0)** 휴무 공지 OCR→음성/게시판 동시 반영은 실무에 바로 쓸 만함. 1-4와 같은 '급식 접근성' 주제로 합쳐 하나의 안으로 제출하는 편이 낫다.
- **2-5 (6.5)** 사회적 가치는 크나 장애·선호 정보는 민감정보. 동의·회수 설계 외에 법적 검토 필요.
- **3-1 (7.0)** 콜백 선택권은 단순하고 체감이 크다. 분위수 예측으로 일정 완충을 두는 AI 적용이 합리적. 약점: 상담센터 통화 데이터 협약, 기존 콜백 예약 시스템과의 차별.
- **3-2 (6.5)** 파급이 크지만 개인정보·기관 간 연계 이슈가 무겁고 행정 전입 인계 절차가 이미 존재.
- **3-3 (6.0)** 위치 정보 민감성, 복지 데이터 활용 맥락이 약함.
- **3-4 (7.0)** 공개 기관정보+협약 입출고로 배분 최적화, 폐기 중량이라는 측정 지표가 명확. 약점: 실제 입출고 데이터 협약, 선행 연구 많음.
- **3-5 (6.5)** 의도 이해 정확도 검증이 어렵고 AI 오판의 위험. 상담사 확인 단계는 좋음.

# 사회보장 데이터 AI 혁신 평가 추가 — 4회차 (5개)

**총평** — 공개 사업 안내로 시연 가능한지가 갈림길이다. 4-1만 날짜 추출이라는 명확한 AI 과업이 있고, 나머지는 최적화·알림 수준이라 AI가 없어도 된다는 질문에 약하다.

| 회차-번호 | 아이디어 | 점수 | 판정 |
|---|---|---|---|
| 4-1 | 식사 배달이 비는 공휴일 | 7.5 | **추천** |
| 4-2 | 복지관 빈 좌석 대기 | 6.5 | 보류 |
| 4-3 | 농촌 이동상담일 | 7.0 | 예비 |
| 4-4 | 형제 함께 맡기기 | 6.5 | 보류 |
| 4-5 | 복지 안내문 주소 확인 | 6.0 | 탈락 |

## 이유 (4회차)
- **4-1 (7.5)** 연휴 끼니 누락은 실제 위험이 큰 문제이고 공지 날짜·끼니 추출은 LLM에 맞는 과업이다. 달력 규칙으로 검산해 환각도 잡는다. 약점: 수행기관 배달계획은 협약 필요, 안부 확인 사업과 겹침.
- **4-2 (6.5)** 편익이 복지관 강좌 한 곳에 한정되고 사회보장 데이터와의 연결이 약하다.
- **4-3 (7.0)** 취지는 좋으나 순회 경로 최적화는 흔한 기법이다. 최장 미방문 간격 제약은 장점. 수요 추정 데이터 확보가 어렵다.
- **4-4 (6.5)** 틈새 불편이라 파급이 작다. 센터별 정원 데이터 협약 부담이 크다.
- **4-5 (6.0)** 반송 사유 분류는 얕고 주소 추정을 하지 않는다면 AI가 할 일이 거의 없다. 개인정보 민감도만 높다.

# 사회보장 데이터 AI 혁신 평가 추가 — 5회차 (5개)

**총평** — 5회차 중 3개(5-1·5-2·5-3)는 데이터를 기관 협약에 의존하고, 5-2는 개인 위치까지 다룬다. 공개 자료만으로 시연 가능한 것은 5-5뿐이다. 반대로 5-4·5-3은 "정확히 일치할 때만 답하고 아니면 사람에게 넘긴다"는 안전 설계가 좋다.

| 회차-번호 | 아이디어 | 점수 | 판정 |
|---|---|---|---|
| 5-1 | 분리된 가구의 난방수리 묶음 방문 | 6.5 | 보류 |
| 5-2 | 폐지 줍는 어르신의 빈 수거 동선 | 6.0 | 탈락 |
| 5-3 | 바우처 결제 실패 사유 한 장 | 7.0 | 예비 |
| 5-4 | 빌려준 복지용구의 맞춤 사용설명서 | 7.0 | 예비 |
| 5-5 | 복지관 자막이 필요한 회차부터 | 7.5 | **추천** |

## 이유 (5회차)
- **5-1 (6.5)** 방문 횟수 감소 효과는 명확하나 일정 조합은 AI 없이 최적화 도구로 풀린다. 여러 사업 담당 기관을 묶는 협약이 사실상 불가능에 가깝다.
- **5-2 (6.0)** 상점 협력과 당일 배출 확인 체계가 전제인데 현실성 근거가 없다. 어르신 위치·수입 관련 개인정보 부담이 크고 안전 문제(도로 이동)는 다루지 않는다.
- **5-3 (7.0)** 시민이 실제로 겪는 막힘이고 오류 코드표 조회 우선 설계는 안전하다. 약점: 핵심이 코드표 조회라 AI 비중이 작고, 코드표는 운영기관 협약이 필요하다.
- **5-4 (7.0)** 모델명 정확 일치만 연결하는 설계는 오답 위험을 막는다. 약점: 공급사 설명서 사용 허가와 라벨 사진 인식 정확도, 결국 '설명서 인쇄' 수준이라 파급이 작다.
- **5-5 (7.5)** 허가받은 강의 영상으로 즉시 시연할 수 있고 ASR 자막과 교안 대조라는 AI 필요성도 분명하다. 시간·금액·주소 오기에 검수 우선순위를 두는 접근이 실무적이다. 개인정보 거의 없음. 약점: 자막 자동 생성 서비스가 이미 많아 차별점은 '숫자·고유명사 우선 검수'뿐이다. 3-1(콜백 시간 선택권, 7.0)을 대체했다.

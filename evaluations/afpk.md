# AFPK 영 플래너 챌린지 · 냉정 평가 (1~58회차)

## 누적 총평
- 강점: 모든 사례에 산수(가상 금액)가 있어 검증이 명확하다. 현금흐름·기회비용 등 재무설계 핵심 개념을 다룬다.
- 약점 1: 'AI = 명세서/약관에서 추출' + '계산은 규칙'이 거의 전부. 재무설계 보고서(6단계)의 질을 AI가 높이는 구조가 아니라 계산기 + 추출기 수준이다.
- 약점 2: 소재 쏠림. '공동·부부·맞벌이' 31개. 변주만 있고 새 개념(위험관리, 세금, 은퇴 설계)이 적다.
- 약점 3: 예시 금액이 작아 '영 플래너'로서 고객 B안(대상 고객 상황)과의 연결이 약해 보일 수 있다 → 공고 조건 재확인 필요.
- 상위 후보: 03-1 연간 청구 겹치는 달 / 01-2 학기마다 소득 끊기는 강사 / 05-4 배달 부업 실질 시급 / 02-2 첫차 구매 vs 대여 / 17-1 변동금리 재설정일.
